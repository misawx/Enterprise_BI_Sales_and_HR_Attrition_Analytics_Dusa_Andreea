## 📋 Project Overview
This repository contains a comprehensive Business Intelligence portfolio built with **Microsoft Power BI**, consisting of two distinct, production-grade analytical reports designed to drive economic and operational decision-making:

1. **Superstore Sales Analytics Report**: Focuses on retail commercial performance, profitability breakdown by category/region, operational risk tracking via return rates, and seasonal sales forecasting.
2. **IBM HR Employee Attrition Report**: Evaluates workforce stability, mapping turnover risks across job roles, business travel frequencies, demographics, and compensation-to-tenure correlations.

### 🛠️ Technical Stack & Features
* **Data Ingestion & Cleaning (Power Query):** Handled complex append/merge workflows, null value handling, data type transformations, and multi-table consolidation.
* **Data Modeling:** Designed robust **star-schema architectures** with one-to-many ($1:^*$) relationships linking fact tables to distinct demographic and regional dimension tables.
* **Advanced DAX Calculations:** Developed custom calculated columns and dynamic measures (e.g., `Profit Margin`, `Return Rate`, `Attrition Rate`, `Sales by Category`, and time-intelligence targets).
* **Interactive Dashboard Design:** Implemented advanced UX features including conditional formatting gradients, dynamic slicers, custom report page tooltips, and bookmark navigation.
